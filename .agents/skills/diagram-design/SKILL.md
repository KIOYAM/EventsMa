# Diagram Design — inline SVG graphics

Generate clean, self-contained SVG/HTML for any visual structure:

- Flowcharts, architecture maps, radar charts, UI illustrations, service blueprints, quote state diagrams.
- Inline SVG only — no external image files; accessible <title>/<desc>; focusable where interactive.
- Sized with viewBox (no fixed width/height) so it scales.
- Colors reference the impeccable-ui token palette.
- Save under assets/diagrams/ and link from code.
