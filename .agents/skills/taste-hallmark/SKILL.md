# Taste & Hallmark — art direction

Use this layer when a page needs a distinct editorial layout (landing pages, public quote, public profile):

- Intentional whitespace: generous margins; placement is asymmetric but deliberate, never accidental.
- Editorial typography: one display face for headings, one neutral face for body; no drop shadows.
- Custom SVG or generated hero visual where stock imagery would go (see image-generation, diagram-design).
- Break the grid deliberately, never by default.
- No marketing claims the product does not implement — e.g. no "LIVE" storefront badge, no leads promise (AGENTS.md §5).
